# Library Books REST API

This API manages books. Each book has an id, title, author and publicationYear.

## List all books

- Method: GET
- Path: /books
- Description: Return all books.
- Request body: None.
- Success status: 200 OK.

## Get one book

- Method: GET
- Path: /books/{id}
- Description: Return the book with the specified ID.
- Request body: None.
- Success status: 200 OK.
